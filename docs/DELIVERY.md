# Smarti Local Search — גרסה 0.1.2

גרסה זו מתקנת הצטברות סריקות בעקבות אירועי תיקיות, ומבטלת את מעבר הספירה המקדים.
הגילוי עובר פעם אחת על כל מיקום; שינויים שוטפים מעדכנים את הקבצים או את תת־התיקייה
שבה התרחש השינוי. קבצים שלא השתנו שומרים על המקטעים והווקטורים שלהם, גם בסריקה
יזומה או בסנכרון לאחר הפעלה מחדש. עבודת אינדוקס שנעצרה חוזרת לתור להמשך.
מוני ההתקדמות משתמשים באינדקסים קטנים ובמטמון SQLite מוגבל, ללא קריאת תוכן או
וקטורים של כל הקבצים בכל רענון.

כל ההחרגות נמצאות בהגדרות > החרגות: שמות תיקיות, תבניות ונתיבים מלאים באותה רשימה,
עם בחירת קובץ או תיקייה באמצעות Windows ושמירה אוטומטית. אין עריכת החרגות בתפריט
של מיקום. החרגות מקומיות ישנות מועברות לרשימה הכללית עם תבנית שמגבילה אותן
למיקום המקורי, כדי לא לשנות בשדרוג את מדיניות ההחרגה במיקומים אחרים.

בדיקות המקור כוללות אירועי Windows אמיתיים, שינוי קובץ בודד, העברה ומחיקה של
תיקיות, אינדקס סינתטי של 150,000 קבצים, עומס מטאנתונים של 2,000 קבצים, ומודל
EmbeddingGemma 2 אמיתי עם PDF/Office/תמונה/אודיו/וידאו. בדיקות הממשק בודקות
שמירה אוטומטית, החרגות מאוחדות, הערכות זמן, RTL ומיקוד החיפוש. פירוט הראיות
וההבחנה בין בדיקות מקור, דפדפן ויישום מותקן נמצאים ב־VALIDATION.md.

המתקין כולל מודל מקומי, שירות הסקה עצמאי, FFmpeg, PDFium, WebView2 וספריות הרצה.
המודל מכיל 484,622,336 בתים. משתמש מותקן אינו זקוק ל־Python, Node או Rust.
להתקנה מעל גרסה קודמת, הרץ את המתקין: נתיב ההתקנה והנתונים נשמרים, היישום
והשירות הישנים נסגרים וקובצי ההרצה המנוהלים מוחלפים. המתקין אינו חתום.

בדיקת השדרוג משתמשת בזהות מוצר מבודדת ובאותם קובצי יישום ומשאבים. היא בודקת
שימור הגדרות ואינדקס, מניעת התקנה כפולה, סגירת שירות ישן, מחיקת DLL מיושן,
חסימת שדרוג לאחור ושימור הנתונים בהסרה. התוצאות משויכות להפצה רק כאשר כל
חתימות היישום והמשאבים תואמות. הבדיקה אינה מתקינה מעל העותק האישי של המשתמש.

לבנייה מלאה: `./scripts/package.ps1`. נדרשים Node 22+, Rust/MSVC, Windows SDK
ו־Python 3.13 במחשב הבנייה. כאשר ספריות ההרצה כבר נארזו ונבדקו והמקור שלהן
לא השתנה, ניתן לאמת משאבים, לתעד חתימות מקורות ולבנות מחדש את Tauri/NSIS.
בדיקות מחשב נקי, קורא מסך, DPI ובורר הקבצים הפיזי, חתימת קוד ומאיצים במחשבים
אחרים עדיין דורשות בדיקה נפרדת. ההסקה נבדקת ב־CPU, וחזרה מ־NPU ל־CPU נבדקת
במחשב זה; אין בכך הוכחה לפעולת מאיץ במחשב אחר.
