# Smarti Local Search — מסירה

נבנתה תוכנת Windows מקומית לחיפוש שמות ותוכן, חיפוש סמנטי וחיפוש לפי קובץ או תמונה. המוצר כולל בחירת תיקיות וכוננים, אינדוקס מתמשך, החרגות, השהיה והמשך, תצוגה מקדימה, מציאת מקטעי מדיה, חיפוש מהיר, מגש מערכת ושילוב אופציונלי בסייר. הממשק בעברית ובאנגלית, עם תמיכה ב־RTL, ערכות צבעים ואייקוני SVG רשמיים של Tabler.

React/TypeScript ו־Tauri 2 מציגים את הממשק; Rust מנהל את החיפוש והאינדקס באמצעות SQLite/FTS5 ו־USearch. שירות הסקה עצמאי מפעיל את EmbeddingGemma 2 באמצעות LiteRT-LM. המתקין כולל את השירות, המודל, ספריות ההרצה, FFmpeg, PDFium, WebView2 ורישיונות התלויות. משתמש מותקן אינו צריך Python, Node או Rust. אין הורדת מודל בהפעלה.

המודל מכיל 484,622,336 בתים, כ־462.17 MiB. המתקין הסופי מכיל 765,139,458 בתים, כ־729.69 MiB. CPU פועל ונבדק עם המודל האמיתי; קיימות בדיקות אתחול והסקה ל־GPU/NPU וחזרה ל־CPU. במחשב הבדיקה GPU נכשל באתחול ולא נמצא NPU זמין. תוצאות אלו אינן מעידות על תמיכה מואצת במחשב אחר.

עברו 12 בדיקות Rust של הליבה והאחסון, בדיקת גאומטריית חלונות, 10 בדיקות Frontend, ארבע בדיקות Python ובדיקת אינטגרציה עם המודל האמיתי. הבדיקה כוללת PDF/Office/תמונה/אודיו/וידאו, חיפוש סמנטי וקוד, שינוי שם, שינוי תוכן, השהיה והפעלה מחדש. נבדקו גם כישלון עסקת הגדרות באמצע, שחזור תצורת המודל הישנה ושינוי מ־256 ל־128 ממדים עם אינדוקס מחדש. בדיקות טיפוסים, Clippy, עיצוב קוד ובניית Frontend עברו. ה־ANN נמדד בנפרד על 100,000 וקטורים סינתטיים; פירוט ומגבלות המדידה נמצאים ב־VALIDATION.md.

המתקין הסופי עבר התקנה והסרה בתיקייה חדשה עם אינדקס מבודד. היישום המותקן אינדקס 13 קבצים, 12 מהם סמנטית, ושמר 15 וקטורים ללא שגיאות. עברו חיפוש, התאמת מקטעי אודיו ווידאו, תצוגת PDF, רישום קיצור דרך, יצירת תפריט מגש ופתיחת חלון חיפוש מהיר באמצעות ה־API המקומי. שירות ההסקה המותקן פעל ללא סביבת פיתוח והצליח לחזור ל־CPU לאחר בקשת NPU. ההסרה מחקה את היישום ושמרה את האינדקס הפרטי. קובצי ההפצה תואמים ל־90 חתימות המקורות שתועדו לפני ההידור.

הנתיבים הם ביחס לתיקיית הפרויקט:

| פריט | נתיב |
| --- | --- |
| מקורות Frontend | `desktop/src/` |
| מקורות Rust | `crates/search-core/`, `desktop/src-tauri/` |
| מקור שירות ההסקה | `inference-host/src/` |
| יישום Release | `target/release/smarti-local-search.exe` |
| מתקין Windows | `artifacts/release/Smarti Local Search_0.1.0_x64-setup.exe` |
| חתימות קבצים | `artifacts/release/SHA256SUMS.txt` |
| חתימות מקורות הבנייה | `artifacts/release/source-manifest.json` |
| דוח אימות האריזה | `artifacts/release/verification.json` |
| בדיקת היישום המותקן | `artifacts/release/native-smoke.json` |
| בדיקת שירות ההסקה המותקן | `artifacts/release/inference-fallback.json` |

להפעלה, התקן באמצעות המתקין ובחר תיקיות באשף. Ctrl+K ממקד את שדה החיפוש; Ctrl+Alt+Space פותח חיפוש מהיר. קובץ היישום לבדו דורש תיקיית משאבים וספריות DLL סמוכות; המתקין הוא קובץ ההפצה.

לבנייה מחדש, פתח PowerShell בתיקיית הפרויקט והרץ `./scripts/package.ps1`. נדרשים Node 22 ומעלה, Rust/MSVC ו־Windows SDK, ו־Python 3.13 במחשב הבנייה. הסקריפט משחזר תלויות, מאמת משאבים, מריץ בדיקות, אורז את שירות ההסקה, בונה מתקין ובודק התקנה והסרה. הבנייה נעזרת באינטרנט; היישום המותקן משתמש במשאבים המקומיים.

נותרו מגבלות אמיתיות: בדיקה חזותית בממשק החי ממתינה לפתיחת נעילת Windows, ובדיקת מחשב Windows נקי, קורא מסך, מנהלי התקן מואצים וחתימת קוד טרם הושלמו. המתקין אינו חתום. שינויים ביומן NTFS גוררים סנכרון מטאנתונים; שחזור ישיר של רשומות USN ו־MFT אינו ממומש. אינדקס ANN נטען לזיכרון, ושירות ההסקה משתמש בתור עדיפויות עם batching מוגבל ולא במאגר מנועים מקבילים אוטומטי. פירוט ב־DECISIONS.md וב־VALIDATION.md.
